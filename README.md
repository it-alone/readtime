# readTime · 读时

三年系统化英语学习计划(基础 · 进阶 · 高阶),Remix SPA 纯前端实现:SM-2 词汇间隔重复主线 + 语法/听力/阅读/发音四模块,学习数据只存本机 IndexedDB,PWA 离线可用。

**在线体验(GitHub Pages):** https://it-alone.github.io/readtime/ —— 推送 `main` 自动构建发布(`.github/workflows/deploy.yml`,`BASE_PATH` 按仓库名子路径部署)。

## 需求背景(原始需求存档)

制定本计划时的原始输入,存档如下:

> 请深入分析多邻国(Duolingo)、流利说及英孚教育等知名英语平台的成熟教学理念与学习路径,结合当前基于 Remix 框架的纯前端项目架构,制定一份为期 3 年的系统化英语学习成长计划。该计划需严格划分为以下三个核心阶段:
>
> 1. **基础阶段(第 1 年)**:重点攻克高频词汇积累、核心语法体系构建及标准发音训练;
> 2. **进阶阶段(第 2 年)**:强化场景化应用短文阅读、听力理解与日常口语表达;
> 3. **高阶阶段(第 3 年)**:深入长篇英文文章研读、复杂语法解析及深度内容理解。
>
> 同时,请梳理出支撑该计划的完整课程体系,确保每个阶段的学习目标清晰、可量化且具备实操性。
>
> **技术实现要求:** 鉴于当前项目是基于 Remix 框架的纯前端架构,请在设计学习计划的同时,重点考虑如何在现有的 README.md 项目中为后续介入服务端预留入口和架构支持。具体包括 API 路由规划、状态管理扩展性等,以便未来能够平滑过渡到全栈开发模式。

## 快速开始(阶段 0 已落地)

```bash
npm install
npm run dev        # 开发服务器
npm run test       # 单元测试(领域层 + IndexedDB 仓储)
npm run build:content  # 内容 TSV(词库/语法)→ public/data JSON(扩内容时用)
npm run typecheck  # 类型检查
npm run build      # SPA 产物 → build/client(可静态托管)
npm run preview    # 本地预览构建产物
```

- 学习计划见 [PLAN.md](./PLAN.md),技术架构见 [ARCHITECTURE.md](./ARCHITECTURE.md)。
- 本阶段为纯前端:数据存于浏览器 IndexedDB(唯一本地存储,不使用 localStorage),学习内容为 `public/data/` 静态 JSON。
- 已实现:首页今日任务台(词汇主线进度 + 语法/听力/阅读/发音今日速通状态;零数据新用户显示三步入门引导)、词汇学习闭环(SM-2 间隔重复、每日任务编排、XP/连胜/勋章)、词库浏览页 `/words`(三年 10,000 词全量视图:年份切换、单元折叠、单词/释义搜索、CEFR 级别筛选、单词与例句发音试听)、语法课程(三年共 3,426 课 = 每年 1,142 课,28 个主题 × 10 种变体循环生成;列表按年级页签 + 50 课/页分页,练习结算计入 XP/日志/连胜,首次完成有加成)、听力训练(今日听写:最逾期词优先,听音选词/听句选义/听音听写,自动播放发音,不干扰 SM-2 调度;精听素材库 2,040 篇 = 第一年 A1/A2 1,432 篇 + 第二年 B1 608 篇,逐句双语音频、单句/全篇连播、盲听模式 + 理解题,计入 XP/日志/连胜)、阅读训练(共 3,366 篇 = A1 816 + A2 1,218 + B1 1,216 + B2 116,16 大场景,列表按 CEFR 页签 + 50 篇/页分页;每篇词汇表 + 理解题,计入 XP/日志/连胜;文中点词查义,生词一键加入 SM-2 复习并标记阅读来源,词汇/听力复习卡片与周报弱词榜可跳回原文)、发音训练(已学词例句 + 已读文章整句交替跟读,语音识别打分,浏览器不支持时自评;计入 XP/日志/连胜,不干扰 SM-2 调度)、学习周报(近 7 天聚合、五模块训练均衡度、复习留存率、弱词榜(标记主线/阅读来源)、下周计划建议,留存率 < 80% 自动减新词)、会话记录持久化、设置(每日新词量、语速、数据概览、全量导出导入——备份含会话历史,覆盖式导入;导入后免整页刷新)、PWA 离线化(manifest + service worker:应用壳/静态资源/内容包分级缓存,构建时全量预缓存全部路由 chunk 与各模块内容索引,内容分片访问过即缓存——断网后词库主线与各模块列表/索引全程可用、学过的详情页可复看,可安装到桌面/主屏)。
- 内容规模:stage1 词库 3000 词(99 个主题单元)+ stage2 词库 3000 词(100 个主题单元:通用主题 + 8 大场景)+ stage3 词库 4000 词(135 个单元:AWL 学术词 + 主题/场景单元,三 stage 全局查重零重复,总计 10,000 词;含音标/释义/中英例句,阅读文章高频生词已优先入库,点词可查),grammar 3,426 课(每 stage 1,142 课 = 手写 22 课 + 批量生成 1,120 课:第一年基础体系 + 第二年完成时/从句/非谓语/引语/it 句式 + 第三年长难句/虚拟语气/倒装/强调/省略/独立主格/衔接词/情态完成式,每主题 10 种练习变体)、阅读 3,366 篇(A1 816 + A2 1,218 + B1 1,216,16 大场景;B2 深度文 116 篇,每篇 ≥ 700 词,正文嵌真实词库例句)、听力精听素材 2,040 篇(第一年 1,432 + 第二年 608,逐句双语文本 + 理解题);语法/阅读/听力内容量大,构建为 index.json(轻量索引,过大再拆 index-part)+ part-XX.json 分片分发(单文件 ≤ 500KB 性能预算,ARCHITECTURE.md §11;词库按 stage 拆成 manifest + part)——列表页只拉索引,详情页按片懒加载。`npm test` 内置内容契约校验(zod,含跨 stage 查重、glossary 入库校验、分片自洽与 ≤500KB 预算卡口、听力句数/题数契约),扩充内容先过测试;批量内容由 `scripts/generate-bulk/` 生成器产出(模板槽位填充 + 词库例句嵌入,append-only 不覆盖手写内容)。
- 语音:全量内容音频包(`/audio/vocab|reading|listening/*.m4a`,macOS 神经语音 Reed 预生成,`npm run audio:gen` 可增量重产),播放走音频包优先、Web Speech TTS 回退(精选清晰发音人,过滤系统搞怪音色);音频经 Service Worker 运行时缓存,听过即离线。
